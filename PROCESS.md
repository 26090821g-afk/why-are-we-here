# Process — How I Used AI

## Tools used

I used an AI assistant (ChatGPT) for the following purposes:

- **Brainstorming**: I asked it to suggest angles on the question "why should design students learn programming when AI can write code." It proposed several directions — I picked the "code as material" angle because it connected to the lecture's discussion of Don Ihde's mediated perception.
- **Drafting**: I wrote the core arguments myself, then asked the AI to help refine the language and transitions between paragraphs.
- **Editing**: I used it to check word count and tighten sentences.
- **Formatting**: I asked an AI assistant to help format the markdown — headings, links, emphasis — since proper formatting is part of the assignment.

## What I kept

The AI helped me rephrase this sentence in the opening paragraph:

> "programming is not just a tool for issuing commands to computers, but **a medium for expressing logic and creativity**"

I kept this because it captured my intended argument precisely — that code is an expressive medium, not just a utility — and the emphasis on "medium" connected well to the materials discussion in the next section. It was better phrased than what I had originally written.

## What I rejected

The AI initially suggested a paragraph arguing that "AI-generated code lacks creativity because it merely recombines existing patterns." I rejected this because:

1. It was **too generic** — this is a common talking point that appears in countless articles about AI, and it didn't reflect my specific perspective as a design student.
2. It was **not my argument**. My point isn't that AI can't be creative, but that *designers who don't understand code lose the ability to evaluate and guide what the AI produces*. The AI's version was a lazy generalization that substituted a cliché for my actual position.
3. The paragraph read well — smooth, confident, plausible — which is exactly why it was dangerous. It sounded like *something* should be there, but it wasn't *my* something.

This experience reinforced the essay's own thesis: the ability to read code (or any generated content) critically and reject what isn't right is precisely the skill that matters.
