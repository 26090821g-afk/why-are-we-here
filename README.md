# Why Should Design Students Still Learn to Program in the Age of Generative AI?

In a context where artificial intelligence can generate code on demand, should design students still learn to program? This question indeed warrants deep reflection. If programming were merely the mechanical writing of syntax, then studying prompt engineering would seem far more efficient. However, as [Dylan Beattie](https://www.youtube.com/watch?v=6avJHaC3C2U) points out in *The Art of Code*, programming is not just a tool for issuing commands to computers, but **a medium for expressing logic and creativity**. For interaction designers, learning to program is not about competing with artificial intelligence in coding speed, but about understanding the underlying logic of digital design and accurately retaining control over the design process.

## Code as Material

Design cannot exist without materials. Painters need to understand pigments, and architects must master steel and concrete. In the realm of digital interaction design, **code is the most fundamental material**. If designers rely entirely on tools to generate code, it becomes difficult for them to engage with the true characteristics of this medium. [Beattie](https://www.youtube.com/watch?v=6avJHaC3C2U) also demonstrates diverse programming languages in his talk to show that code possesses a *unique expressiveness* and *logical beauty*.

## A New Way of Thinking

Learning to program changes how designers solve problems. This training cultivates the ability to **systematically break down problems**. Once designers master code logic, they are no longer restricted to drawing static pages; instead, they can conceptualize dynamic systems. For instance, designers can evaluate latency during data transmission and analyze its impact on user experience. This understanding makes design proposals far more feasible.

## The Limits of AI-Generated Code

Code generated by artificial intelligence is built on *statistical probability*; it excels at replicating existing patterns, yet it cannot perceive genuine human emotions. Similarly, AI can quickly output a segment of interface logic, but it struggles to judge whether such a design can relieve user anxiety. If designers lack a foundation in programming, they can easily accept standardized solutions provided by the system **without question**. Designers who understand code can inspect generated programs, identify logical flaws, and make targeted adjustments. This capability enables designers to guide technology to better serve human needs.
